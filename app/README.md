# ⛓️ ChainReaction — 0G Cybernetic Command Deck

An advanced visual robotics control cockpit that bridges **decentralized AI compute**, **on-chain Ethereum behavior gating**, and **immutable decentralized storage** using the **0G stack** to control the expressive Pollen Robotics Reachy Mini.

### Deployed Features:
- 🌌 **Glassmorphic Synth UI**: Premium futuristic styling with neon glows.
- 🛸 **Holographic Telemetry HUD**: Real-time virtual joint coordinate dials (head roll/pitch/yaw and antennas).
- 🧬 **0G Behavior Lab**: Visual macro posing sequencer + 0G Storage schema exporter.
- ⚡ **Block Ledger Diagnostics**: Real-time testnet block heights, MetaMask RPC balance tracker, and network gas streams.
- 🛠️ **Developer Sandbox**: Frictionless single-click demo flow.
